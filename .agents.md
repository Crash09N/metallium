# Nativium — Agent Guide (all AIs)

Single project guide for humans and coding agents. Prefer this file over any other agent markdown.
`CLAUDE.md`, `.claude.md`, `.cursorrules`, `.gemini.md`, `.agy.md`, `.junie.md` are symlinks to **this** file (`.agents.md`) —
edit only `.agents.md`, never replace the symlinks.

## Project status

Early implementation (since 2026-10-18); alpha 0.1.0-alpha, pre-1.0 (2026-10-20). Architecture and evidence: `docs/research/`.
Iris adapter design: `docs/design/`. State: `docs/STATUS.md`, plan: `docs/ROADMAP.md`, release: `docs/RELEASE.md`.
- Modules (`settings.gradle`): core, `nativium-iris` (LGPL-3.0 Iris adapter), `nativium-gl` (OpenGL to Metal), `nativium-voxy-natives` (macOS arm64 Voxy natives).
- Build: JDK 25, `./gradlew build`; release jar: `./gradlew releaseJar` (nests the three modules). Metal smoke test (macOS only): `./gradlew metalSmokeTest`.
- Game tests (local, macOS): `./gradlew runClientGameTest` with `-PwithSodium`, `-PwithIris`, `-PwithGl`, `-PwithVoxy=<jar>`,
  `-PextraMods=a.jar,b.jar`, `-Pshaderpack=<name>`, `-Pbench` (+ `-PbenchScene/-PbenchSeconds/-PbenchVsync/-PbenchWindow/-PbenchDisplay/-PbenchFullscreen/...`), `-PperfCounters`.
  Production-style launch with the release jar: `./gradlew runClientProd -PplayProd=<instance copy>` (+ `-PplayWorld=<save>`).
- `src/main/java/de/nprmedia/nativium/backend` = renderpearl Metal backend (started from Metallum, MIT — keep file headers).
- Priority order set by the owner: Iris shader-pack support is the top feature priority after a working backend.
- Renamed from **Metallium** to **Nativium** on 2026-10-21 (mod id `nativium`, package `de.nprmedia.nativium`; Metal now,
  an NVIDIA path later). Old names survive only in `LegacyMigration`, the deprecated `dev.metallium.api.MetalliumRuntime`
  shim, the `"metallium-gl"` opt-in key fallback, `breaks: metallium`, dated docs/research notes, the GitHub repo URL and
  the folders outside the repo (`../metallium-research`, `~/Desktop/Metallium`) — those stay as they are.

## Working rules (learned 2026-10-20)

- GitHub Actions CI is disabled: test locally only.
- Every game window runs through the gpu-lock script (`gpu-lock.sh`, `--exclusive` for benchmarks). The owner's own game has priority.
  Benchmarks only when the owner is away, window focused, native 2560x1440 on the 144 Hz display; mark invalid rows (`bench-env: INVALID`).
- Never launch tests in the owner's play instance (use a copy).
- Test mods with the release jar in a production-style launch (`runClientProd`) before claiming they work; dev-only test aids hid the Voxy natives crash.
- Never leave hung windows for the owner: hard timeouts, kill what you started.
- Downloaded mods, shader packs and instances live only in `../metallium-research`, never in the repo.
Do not treat this file or any README as proof of how upstream projects work — verify in source.

## Model routing for multi-agent work (Claude)

Owner preference (2026-10-12, replaces earlier routing) — pick the cheapest model that still does the job well:

| Work | Model |
|------|-------|
| Simple commands and mechanical steps: running checks/tests, git, file listings, status polling, CI-log fetching, renames, one-line edits | **Haiku** (`claude-haiku-4-5-20251001`) |
| Other simple tasks: research, reading/mapping code, web lookups, summaries, CI-log triage, simple/well-specified coding (small fixes, tests, copy changes) | **Sonnet** (`claude-sonnet-5-5`) |
| Everything else: features, refactors, non-trivial bug fixes, architecture/design plans, code review, fix rounds | **Opus** (`claude-opus-5-5`) — the default |
| Only very specific, extremely demanding reasoning tasks where it clearly pays off — **and only after the owner has agreed for that specific task** | **Fable** (`claude-fable-5-1`) |

Never pick Fable on your own initiative: ask the owner first, per task, and say why Opus is not enough. Don't let Haiku write
production code beyond mechanical edits.
