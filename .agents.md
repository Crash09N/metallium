# Metallium — Agent Guide (all AIs)

Single project guide for humans and coding agents. Prefer this file over any other agent markdown.
`CLAUDE.md`, `.claude.md`, `.cursorrules`, `.gemini.md`, `.agy.md`, `.junie.md` are symlinks to **this** file (`.agents.md`) —
edit only `.agents.md`, never replace the symlinks.

## Project status

Early implementation (since 2026-10-18). Architecture and evidence: `docs/research/`. Iris adapter design: `docs/design/`.
- Build: JDK 25, `./gradlew build`. Metal smoke test (macOS only): `./gradlew metalSmokeTest`. CI: `.github/workflows/ci.yml`.
- `src/main/java/dev/metallium/backend` = renderpearl Metal backend (started from Metallum, MIT — keep file headers).
- Priority order set by the owner: Iris shader-pack support is the top feature priority after a working backend.
Do not treat this file or any README as proof of how upstream projects work — verify in source.

## Credits and code reuse

- Every upstream project whose code or ideas Metallium uses must be credited in `README.md` → "Credits & licenses",
  stating how it is used (runtime dependency / adapted code / ideas only) and its licence.
- When code is actually copied or adapted, update that README row in the same commit and keep the original copyright
  and licence notices in the copied files.
- Never copy code from Sodium (PolyForm Shield) or MetalRender (custom licence; owner disallows AI use). Ideas only.
  mcopt code only from commit `09fea99` onward. Iris-derived code stays in the LGPL-3.0 Iris adapter module.

## Model routing for multi-agent work (Claude)

Owner preference (2026-10-12, replaces earlier routing) — pick the cheapest model that still does the job well:

| Work | Model |
|------|-------|
| Simple commands and mechanical steps: running checks/tests, git, file listings, status polling, CI-log fetching, renames, one-line edits | **Haiku** (`claude-haiku-4-5-20251001`) |
| Other simple tasks: research, reading/mapping code, web lookups, summaries, CI-log triage, simple/well-specified coding (small fixes, tests, copy changes) | **Sonnet** (`claude-sonnet-5-5`) |
| Everything else: features, refactors, non-trivial bug fixes, architecture/design plans, code review, fix rounds | **Opus** (`claude-opus-5-5`) — the default |
| Only very specific, extremely demanding reasoning tasks where it clearly pays off — **and only after the owner has agreed for that specific task** | **Fable** (`claude-fable-5-1`) |

Never pick Fable on your own initiative: ask the owner first, per task, and say why Opus is not enough. Don't let Haiku write
production code beyond mechanical edits.
