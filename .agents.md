# Nativium — Agent Guide (all AIs)

Single project guide for humans and coding agents. Prefer this file over any other agent markdown.
`CLAUDE.md`, `.claude.md`, `.cursorrules`, `.gemini.md`, `.agy.md`, `.junie.md` are symlinks to **this** file (`.agents.md`) —

## Project status

**1.0.0 released 2026-10-24** (alpha 0.1.0-alpha on 2026-10-20). The project is paused after 1.0; the next two tracks,
**Apple-native features** (MetalFX, Game Mode, ray tracing) and the **NVIDIA path** (Nvidium-style GPU-driven terrain,
DLSS), are **in planning**: `docs/design/next-phase-planning.md`. Implementation of any item starts only with the
owner's go for that item.
State: `docs/STATUS.md` (newest entry first), plan: `docs/ROADMAP.md`, release + known limits: `docs/RELEASE.md`,
benchmarks: `docs/benchmarks/` (current baseline `release-2026-10-24.md`), design notes: `docs/design/`, research: `docs/research/`.
- Modules (`settings.gradle`): core, `nativium-iris` (LGPL-3.0 Iris adapter), `nativium-gl` (OpenGL to Metal), `nativium-voxy-natives` (macOS arm64 Voxy natives).
- Build: JDK 25, `./gradlew build`; release jar: `./gradlew releaseJar` (nests the three modules). Metal smoke test (macOS only): `./gradlew metalSmokeTest`.
- Game tests (local, macOS): `./gradlew runClientGameTest` with `-PwithSodium`, `-PwithIris`, `-PwithGl`, `-PwithVoxy=<jar>`,
  `-PextraMods=a.jar,b.jar`, `-Pshaderpack=<name>`, `-Pbench` (+ `-PbenchScene/-PbenchSeconds/-PbenchVsync/-PbenchWindow/-PbenchDisplay/-PbenchFullscreen/...`), `-PperfCounters`.
  Production-style launch with the release jar: `./gradlew runClientProd -PplayProd=<instance copy>` (+ `-PplayWorld=<save>`).
- `src/main/java/de/nprmedia/nativium/backend` = renderpearl Metal backend (started from Metallum, MIT — keep file headers).
- Priority order set by the owner: Iris shader-pack support is the top feature priority after a working backend.
- Renamed from **Metallium** to **Nativium** on 2026-10-21 (mod id `nativium`, package `de.nprmedia.nativium`; Metal now,
  an NVIDIA path later). Old names survive only in `LegacyMigration`, the deprecated `dev.metallium.api.MetalliumRuntime`
  shim, the `"metallium-gl"` opt-in key fallback, `breaks: metallium`, dated docs/research notes. The GitHub repository was renamed to `Crash09N/nativium` on 2026-10-24. The local folders were renamed on 2026-10-23: `~/Desktop/Nativium/{nativium,nativium-research,nativium-play,nativium-playprod}`.

## Start here (handoff for the next agent)

- Main branch: `claude/lucid-heisenberg-f4n1hp` (GitHub `Crash09N/nativium`, renamed from `metallium` on 2026-10-24;
  the old URL redirects). 1.0.0 = commit `e270ae2` or later on that branch. Work on a feature branch; the owner merges
  or asks the coordinating agent to merge. Parked work: `parked/gl-coverage` (GL coverage scanner, pre-rename package).
- Read `docs/STATUS.md` top entries and `docs/RELEASE.md` "Known limits" first; they list what is open.
- Regression suite before anything is merged (all through `tools/gpu-lock.sh`, look at every screenshot, do not trust
  exit codes alone): `./gradlew build`; `runClientGameTest` vanilla; `-PwithSodium`; `-PwithIris -Pshaderpack=<Complementary Reimagined>`;
  Voxy + pack (`-PwithIris -PwithGl -PglMods=voxy -PwithVoxy=<jar> -PextraMods=<nativium-voxy-natives jar> -Pshaderpack=...`);
  `-PwithIris -PwithDH -Pshaderpack=...`; Rethinking Voxels (geometry shaders); `-PwithSodium -PconformanceTest`; `-PglintTest`;
  and the release jar: `-PreleaseJarTest [-PreleaseJarIris]` (+ the Voxy/DH/pack variants). Reports and screenshots:
  `build/run/clientGameTest/`. Comparing against OpenGL: add `-PbackendOff`.
- New features get a system property / option to turn them off (A/B), a game test with screenshots, and are on by
  default only after the suite passes with them on and off.
- Voxy test pitfalls: the test world has LODs only ~64-150 blocks around spawn (judge at the fixed camera
  `tp -24 161 -48 30 30`, vanilla rd 4); `VoxyConfig.enableRendering=false` does not stop Voxy under packs; dev game
  tests need the natives jar via `-PextraMods` (the release-jar test loads it nested).
- Minecraft 26.3 uses reversed-Z depth; Iris's `TransformPatcher.patchDepth` handles pack depth reads (see `VoxyIrisBridge`).

## Working rules (owner)

- GitHub Actions CI is disabled: test locally only (macOS, Apple Silicon).
- Every game window runs through `tools/gpu-lock.sh` (`--exclusive` for benchmarks). The owner's own game has priority.
- Benchmarks only when the owner is away: native 2560x1440 **fullscreen on the 144 Hz Odyssey G5** (not the 60 Hz main
  display), window focused, AC power; rows without `bench-env: VALID` do not count. While the owner uses the Mac: no
  fullscreen windows, and pause game tests when they ask.
- Never launch tests in, or modify, the owner's own play instance (Prism); reading its logs is fine. Use a copy
  (`tools/make-run-instance.sh`).
- Never connect to multiplayer servers and never log into accounts from tests.
- Test mods with the release jar in a production-style launch (`runClientProd` / `-PreleaseJarTest`) before claiming
  they work; dev-only test aids hid the Voxy natives crash.
- Never leave hung windows for the owner: hard timeouts, kill what you started (and your own wait loops).
- Downloaded mods, shader packs and instances live only in `../nativium-research`, never in the repo, never pushed.
- Minimum macOS: Metal 4 / macOS 26 (owner OK, 2026-10-23).
Do not treat this file or any README as proof of how upstream projects work — verify in source.
